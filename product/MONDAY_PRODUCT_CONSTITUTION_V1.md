# Monday Product Constitution v1

Source authority: recovered `MONDAY_APP_MASTER_PRODUCT_BIBLE_2026-08-27` + `MONDAY_APP_MASTER_BUILD_ORDER_2026-08-27` + validated Body v0.4 mutation lineage.

## North star
Monday is a familiar, controllable premium consumer application in which ordinary software objects can remember, reason, evolve and act. It is not a chatbot skin, agent dashboard, model picker, developer telemetry surface, site showcasing MondayID, or cyberpunk/Jarvis shell.

## Mandatory shell
- Stable iPhone navigation: Home / Chats / Create / Spaces / You.
- Search and Activity are globally available.
- Library stays a conventional file surface with semantic depth added, never substituted.
- Desktop: sidebar + center + optional inspector.
- Every important intelligent path has an explicit manual equivalent.

## Home
Home is a Continuum, not a dashboard: last living thread, current world state, actual running Work, recent/pinned user objects and one universal composer. Internal architecture, Product Bible, native-body telemetry and TestFlight status are not consumer Home content.

## Runtime laws
- Preserve raw SignalEvent losslessly.
- Material fragments end as APPLIED / ANSWERED / PERSISTED / SUPERSEDED / OPEN.
- Generated != Executed != Read back != Verified.
- Long Work is a durable Task with checkpoints and receipts, not model context.
- Corrections create detectors/regression behavior, not acknowledgement prose.
- Host/model/chat is a replaceable cell, not MondayID identity.
- Provider routing is capability/latency/cost/privacy/reliability/health aware.
- Source unavailable != no result.
- Irreversible/consequential actions require Human Gate; reversible actions need truthful Undo semantics where possible.

## Release vetoes
Reject a release if it is a renamed ChatGPT clone, a left-sidebar chat app presented as the whole product, an agent/status dashboard, a glowing AI orb/cyberpunk network, an orange task-manager shell, a model-picker identity, progress theater, fake background work, fake learned memory, fake verification, or a beautiful mockup substituted for implementation.

## Definition of done
A new user can use Monday immediately; a returning user experiences real continuity; long Work survives session boundaries; memory is inspectable; significant actions expose causal state/receipts; manual paths exist; privacy/authority remain user-controlled; provider/model changes do not destroy product coherence; AntiMonday regression tests pass.
