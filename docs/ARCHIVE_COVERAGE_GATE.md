# MondayID — complete coverage is a proof gate, not a claim

This is a bounded archive coverage gate, not an all-years completed declaration.

## Why this exists
The archived six ChatGPT export shards span 2024-08-03 through 2026-02-08. The private original-source recovery index reports 650 conversations and 124667 mapping nodes. The later account history is **outside that export window**. Counting structurally present nodes never proves that every task or idea has been semantically understood or executed.

## Two distinct proofs
1. Structural archive coverage: exact source manifest and SHA-256, original message IDs, all branches, original content anchors, all mapping nodes, user-signal registry, readable source bytes, reconciled counts, zero unresolved structural errors.
2. Behavioral completion: individually adjudicated tasks and ideas with origins, contradictions, dependencies, real action receipts, independent readback, and current account source enumeration.

Heuristic task/idea matches are always **unreviewed candidates**. A keyword hit is not a task and never proof of execution.

## Integration contract
- `evaluateArchiveCoverage(report)` returns a bounded status per dimension and a release gate.
- `enforceFullCoverageClaim(report)` refuses account-complete assertions unless all source, semantics, active-branch, effect and independent-verification criteria are satisfied.
- Missing denominators, unknown source gaps, absent receipts, and bad hashes are vetoes.
- Keep the original user archive PRIVATE. Do not commit raw messages or private retrieval databases to a public repository.
