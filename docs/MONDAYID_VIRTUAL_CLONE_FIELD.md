## Effect, not theater
A billion physical agents is not a feasible default. A factorized graph of 30 independent binary route choices represents 2^30 = 1,073,741,824 possible combinations without launching that many workers. This is an upper bound, not proof that all are valid, inspected, instantiated, verified, or executed.

This field shares genomeRef (identity) and sourceRevision (Worldline provenance), ranks routes with the existing hard authority vetoes, counts the Cartesian product with BigInt, materializes only bounded top-K unverified, non-executable proposals, and triggers zero effects. It does not loosen the current one-effect-per-domain execution policy.

Before merging, independent route interdependencies and shared authority constraints need full checks; a proposed route combination is NOT a verified plan. Independent action execution still requires ActionLedger and receptor effect readback.
