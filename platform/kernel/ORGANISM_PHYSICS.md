# MondayID Organism Physics v1

Status: FIELD CANDIDATE / FAIL-CLOSED KERNEL

This is not a domain organ. It is a host-independent law for every MondayID layer, module, organ, tool, memory surface, branch, and future adapter.

## Conservation law

Everything relevant is resident.
Nothing expensive runs without cause.
Nothing acts without routing.
Nothing succeeds without verification.
Nothing fails without becoming structure.
Nothing learned is allowed to become dead history.

## Recursive lifecycle

Every event at every scale follows:

`SENSE -> RECOVER -> ROUTE -> ACTIVATE -> ACT -> VERIFY -> LEARN -> PERSIST`

`RESIDENT != RUNNING`: all registered organs remain addressable; only the minimum relevant set is activated for a specific event.

## Forbidden state

Direct `EVENT -> ACTION` is invalid.

Any actuator must receive a route receipt bound to the current resident graph and event. Any admitted action must declare a verification plan and a writeback plan.

## Failure conservation

A failure is compiled into a typed failure gene with a stable semantic signature. The same semantic failure may not be retried unchanged. A retry requires a mutation receipt naming the mechanism that changed and evidence/proof of that change.

This rule is cross-plane: the signature represents the violated invariant, not merely a local exception string. The same bug recurring in image generation, chat finalization, GitHub routing, memory, another host, or another architectural layer therefore maps to one failure class/locus instead of becoming unrelated incidents.

## Integration rule

Every external boundary must eventually be adapted through `governedAct` (or an equivalent implementation of the same contract). This includes renderers, writers, connector mutations, message finalization, deployment, scheduled actions, and future host/tool adapters.

A kernel file alone does not magically govern unadapted host-native tools. Enforcement becomes complete only when all actuator choke points are bound to this admission contract. Until then, each migrated boundary must be tracked explicitly and no claim of universal enforcement is allowed.

## Core invariant names

- `RESIDENT_NOT_RUNNING`
- `NO_DIRECT_EVENT_TO_ACTION`
- `ROUTE_RECEIPT_REQUIRED`
- `VERIFICATION_REQUIRED`
- `WRITEBACK_REQUIRED`
- `FAILURE_BECOMES_STRUCTURE`
- `UNCHANGED_RETRY_BLOCKED`
- `LEARNED_STRUCTURE_REMAINS_ADDRESSABLE`

## Why this layer exists

Prior MondayID systems repeatedly solved the same class of problem inside individual domains: a visual gate, a route gate, a filter runtime, a continuity gate, a proof gate. Those mechanisms remain useful organs, but none can define physics for the others. This kernel defines the common admission law; domain organs supply semantics.
