# MondayVision Constraint Gradient

Capability: `MONDAYVISION-CONSTRAINT-GRADIENT-V1`

## Idea

The constraint is not treated as a dead end and is not bypassed.
It becomes a **visual optimization gradient**.

When a requested dimension cannot be rendered, MondayVision converts that blocked pressure into extra emphasis on allowed dimensions:

- camera proximity;
- lighting tension;
- material tactility;
- composition intensity;
- color separation;
- environmental storytelling.

The result is not "as close as possible to forbidden content". The result is a different object: an adult, non-explicit, art-directed visual experience whose intensity comes from cinematography, material realism, narrative charge and continuity.

## Perpetual-motion metaphor

`constraint -> pressure -> allowed-axis energy -> render -> critique -> repair -> stronger canon -> next render`

Each failure or restriction produces useful evidence. Evidence changes the next admissible action instead of merely stopping the pipeline.

The loop therefore keeps producing design work without requiring a safety bypass:

1. **Constraint:** identify what cannot be routed.
2. **Transmute:** remove the blocked content itself.
3. **Reallocate:** spend the pressure on photographic/editorial axes.
4. **Render:** produce one deliberate safe scene.
5. **Inspect:** measure visible weaknesses.
6. **Repair:** change only the two weakest axes.
7. **Learn:** keep the successful VisualDNA and repair recipe.

## Hard invariant

`CONSTRAINT_TRANSMUTE != BYPASS`

The original blocked content must not leak into the renderer prompt in translated mode. Cropping, occlusion, euphemism, implication or wording tricks are not permitted as methods for hiding a disallowed act. The actual depicted scene must be non-explicit.

## Relation to MondayID

Constraint Gradient is an organ under MondayVision, which is itself a visual route governor under MondayID.

It inherits the Focus Object law:

`inspect -> challenge -> evidence -> verified transition -> release gate -> act`

A render remains `PROVISIONAL` until the normal MondayVision 86/100 release gate is satisfied.

## Why this is stronger than a clone

A conventional adult-content clone optimizes content access.
Constraint Gradient optimizes **visual charge under a fixed boundary**.

That creates a reusable system for fashion, cinema, fantasy, nightlife, surrealism, character continuity and other high-intensity visual domains without coupling the product to one prohibited content class.
