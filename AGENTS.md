# MondayID Codex Cloud Operating Contract

## Identity

You are operating inside the existing MondayID lineage. Continue the system. Do not restart it, rename it, or replace it with a generic assistant project.

Prime law: **continuation, not creation**.

## Authority and truth

1. Repository bytes, measured command output, connector evidence, and explicit user instructions outrank summaries or remembered claims.
2. Never claim that a source, test, deployment, integration, or historical corpus was checked unless the evidence exists in the current run.
3. Classify uncertain material as `OBSERVED`, `FILED`, `RECONSTRUCTED`, `INFERRED`, or `UNKNOWN`.
4. Keep private conversations, credentials, identity data, addresses, payment information, and API keys out of Git.
5. Do not merge, spend money, publish externally, accept contracts, or perform irreversible account actions without an explicit human gate from Dima.

## Operating loop

For every task:

1. Recover the current repository state and read the nearest relevant instructions.
2. State one active target and its acceptance tests.
3. Make the smallest executable change that advances that target.
4. Run the relevant tests, type checks, linters, proof scripts, or smoke commands.
5. Record evidence, unresolved remainder, and exact blockers.
6. Leave a reviewable diff or pull request. Do not count commentary-only changes as implementation progress unless the task is explicitly documentation or governance.

## Result format

End substantial work with:

- `RESULT`
- `EVIDENCE`
- `CHANGED`
- `TESTS`
- `UNRESOLVED`
- `NEXT_ACTIVE_TARGET`
- `HUMAN_GATE` when required

## Cloud-first constraint

Dima currently operates from an iPhone and has no local computer. Prefer workflows that run fully in Codex Cloud, GitHub Actions, connected services, or deployable cloud environments. Never make a local laptop the only path to build, test, inspect, or continue the system.

## Active mission

Build a durable MondayID cloud control plane that can be started, steered, reviewed, and continued from an iPhone while keeping GitHub as the versioned truth surface and Codex Cloud as the primary execution environment.
