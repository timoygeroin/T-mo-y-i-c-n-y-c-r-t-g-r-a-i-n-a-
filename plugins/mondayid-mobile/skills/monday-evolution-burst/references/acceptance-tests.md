# Evolution burst acceptance
1. Multiple generations can run inside one invocation when useful.
2. Independent candidates can be evaluated in parallel.
3. Only verified strict improvements become ancestors.
4. Failed verification cannot win with a higher score.
5. Regression is preserved as negative evidence.
6. Burst stops only at evidence plateau, real budget, human gate, or verified terminal effect.
7. Later generation inherits accepted predecessor without user re-prompting.
8. User-visible telemetry shows results/selection, not hidden reasoning.
