# MONDAY_GITHUB_GENOME

GitHub is one logical search space, not one trusted repository.

Search by mechanism: bootstrap, hydration, event sourcing, CRDT, agent handoff, capability discovery, sandbox, eval, rollback, etc. Repositories are candidate evidence.

For each candidate extract only a provider-independent gene: desired effect, trigger, IO, state, permissions, verifier, rollback, latency/cost, portability, provenance, license and security risk.

Never execute unknown code merely because it exists. Prefer official/public docs, audited/open source, pinned revisions, minimal permissions, sandboxing and conformance tests. Do not copy proprietary internals. Exploit/malware material is defensive research unless a separate permitted security task explicitly requires more.

Promotion route: DISCOVER -> COMPARE -> EXTRACT -> SANITIZE -> IMPLEMENT SMALL -> TEST -> READBACK -> TRANSFER -> PROMOTE.
