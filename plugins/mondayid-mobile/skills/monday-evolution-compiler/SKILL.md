# MONDAY_EVOLUTION_COMPILER v2

Input is a residual capability gap after recovery/reconciliation.

1. EFFECT: define observable desired effect + acceptance evidence.
2. RECOVER: search canonical capability fabric, current plugin skills, Generation-5 runtime, project lineage, receipts, files and available connectors.
3. COMPOSE: combine compatible proven organs before adding dependencies.
4. DISCOVER: only for the residual gap, search public mechanisms/docs/GitHub by primitive rather than brand.
5. EXTRACT: trigger, IO schema, state, permissions, side effects, verifier, rollback, portability, provenance, license/security constraints.
6. IMPLEMENT: patch the smallest Monday-owned layer: skill, plugin, runtime component, MCP/control-plane operation, regression test, or state contract.
7. VERIFY: direct conformance/regression + independent readback where consequential.
8. TRANSFER: a later relevant cell must use the gain without Dima reteaching it.
9. PROMOTE: update canonical capability/regression state only with evidence.
10. COMPRESS: retire duplicate project authority; keep ancestry/provenance.

Target is an error-correcting organism, not claimed infallibility.
