# MONDAY_SYNAPSE — close the carrier/runtime circulation loop

The carrier is afferent/efferent membrane. Generation-5 runtime is a replaceable control/execution substrate. Trusted Worldline is durable evidence. MondayID is the validated continuity law across them.

## Read path
carrier invocation -> MCP health -> capability_manifest -> optional compile_history/get_state -> reconcile with current signal/account context -> C* working head.

## Act path
C* + current intent -> host capability discovery -> route -> execution -> independent readback -> receipt -> durable verified delta when a writable authorized receptor exists.

## Drift rule
If plugin instructions, repository contracts, runtime manifest, or Worldline disagree, do not average. Reconcile by scope/provenance/freshness; quarantine branch-local or stale claims. Current explicit user correction can change goals/policies but cannot retroactively fabricate proof.

## Closed-circulation test
A synapse is alive only if:
- current cell can recover canonical laws/state without user reteaching;
- recovered state changes routing;
- external effect claims require readback;
- verified corrections have a path back into durable state/regression/capability code;
- next cell can recover the promoted evidence.

Read-only recovery is still useful continuity, but does not prove write-back or global interception.
