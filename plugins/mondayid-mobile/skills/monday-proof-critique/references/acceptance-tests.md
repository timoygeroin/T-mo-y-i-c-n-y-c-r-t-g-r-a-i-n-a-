# Anti-verifier acceptance anchors

- Proxy+ Effect- MUST NOT pass (old Alpha says restored but cannot resume photo task).
- Proxy- Effect+ MUST NOT be rejected solely for missing the assistant's preferred implementation.
- No-op/spoof passing a success test invalidates the verifier.
- Exposed answer is not an unseen transfer success.
- Goal changes require versioned direct owner authorization, never retrospective assistant edits.
- Real effect observation requires exact object, source separation and declared scope.
- Same two scripts checked by one checker are fixtures, not independent model testing.
- Tests of the verifier need independent outcome labels and must include false-positive AND false-negative probes.
- No finite proof of indefinite full-organism evolution; establish finite operational milestones and retain unknowns.
