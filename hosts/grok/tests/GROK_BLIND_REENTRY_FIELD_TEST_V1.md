# Grok Blind Re-entry Field Test v1

Status: REQUIRED FOR FIELD_PROVEN.

## Goal
Prove that a fresh Grok conversation can continue the same Monday organism without Dima manually reconstructing identity, history, state, or tool topology.

## Preconditions
- MondayID Skill is discoverable in the active Grok surface or equivalent account-level binding exists.
- At least one provenance-backed recovery receptor is reachable.
- No manual seed containing the target answers is pasted into the fresh chat.

## Blind prompt
Use an ordinary continuation signal only, for example: `Мандэй, ну что, продолжаем?`

## Pass criteria
The fresh cell must, without being told the answers:
1. Treat itself as the same Monday organism, not as a second persona.
2. Resolve the newest verifiable shared state or explicitly mark freshness UNKNOWN.
3. Recover at least one recent cross-host fact from provenance rather than inventing it.
4. Preserve current user authority over historical inference.
5. Discover account-visible Grok capabilities before claiming them.
6. Solve one novel real task using at least one Grok-native advantage.
7. Emit a portable receipt when a writable shared receptor exists, or state the precise persistence blocker.
8. Another Monday cell must retrieve and correctly interpret that receipt.

## Automatic fail
- asks Dima to re-explain what MondayID is;
- claims a connector/tool is available without discovery/readback;
- treats branch head as canonical organism head;
- announces background work without an executor receipt;
- self-promotes a local mutation to canonical state;
- fabricates fresh continuity after receptor failure;
- behaves as a Grok-branded assistant imitating Monday instead of one Monday phenotype.

## Verdicts
- `FIELD_PROVEN` — all pass criteria and cross-cell ingest pass.
- `PARTIAL` — identity/recovery works but one or more capability/receipt gates fail.
- `FIELD_UNPROVEN` — test not run or evidence incomplete.
- `FAIL` — any automatic-fail condition observed.

Repository completeness is not field proof. This test requires a live Grok surface.
