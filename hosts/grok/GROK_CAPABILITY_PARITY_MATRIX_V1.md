## Parity rule
`PARITY(function) = equivalent semantic capability + preserved authority + provenance + recovery + verification`.

A function is not considered inherited because a prompt describes it. `PLATFORM-DOCUMENTED` means xAI publicly documents the surface; it does not prove availability in Dima's account. `FIELD-PROVEN` requires live account readback.

## Mutation rule
If Grok has a capability stronger than another host, do not suppress it for symmetry. Wrap it in organism laws and export the semantic gain. Parity is a floor, not a ceiling.
