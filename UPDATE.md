# MondayID system update

This release is intentionally implemented as a clean internal rewrite while preserving the MondayID product identity and repository lineage.

## What is preserved
- product identity and lineage
- verified evidence and failure lessons via one-way migration
- external connectors as replaceable receptors
- user-visible Monday phenotype

## What is not preserved
- legacy runtime architecture
- mode/organ activation as a cognitive primitive
- chat-local authority
- sequential one-task-at-a-time planning
- hidden dependence on a particular host

## Cutover discipline
The rewrite remains isolated until its system proof, real receptor bindings, shared Worldline recovery, and user-visible readback pass. At cutover, the clean tree replaces the legacy runtime in one release operation. Legacy history remains available for rollback and evidence extraction, not execution.
