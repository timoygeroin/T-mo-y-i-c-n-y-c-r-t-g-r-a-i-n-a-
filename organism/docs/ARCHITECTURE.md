# Architecture

`SwiftUI body → HTTP/MCP receptor → SQLite organism → receipts/evidence/continuity`.

- Raw signals are persisted before interpretation.
- Obligations make incompleteness explicit and block global readiness.
- VERIFIED receipts require registered evidence IDs.
- Irreversible actions require a human gate.
- Continuity packets persist state across chat/month boundaries.
- No `WKWebView`, web shell, or Sites deployment is part of this body.
